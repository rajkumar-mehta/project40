MIKA'S 40 SECRETS — v1.1

What's new in v1.1
------------------
1. Removed the extra "THE MYSTERY HAS BEEN SOLVED" confirmation screen after a correct answer.
2. Correct answer now goes directly to the gift/surprise screen.
3. Gift screen randomly chooses one of:
   - ENJOY TODAY'S GIFT
   - OPEN TODAY'S SURPRISE
   No parentheses; only one phrase is shown at a time.
4. Added the gift-box visual.
5. Scoreboard labels corrected to:
   - Current Streak
   - Best Streak
6. White Flags scoreboard icon is forced to render white.
7. Preserved all passing v0.7 logic:
   - newest secret first
   - future secrets hidden
   - missed secrets remain playable
   - correct date-filtered scoreboard
   - green open locks for solved
   - white flag replaces padlock for surrendered
8. Dashboard behavior:
   - Scorecard stays frozen/sticky
   - "YOUR SECRETS" stays frozen/sticky
   - only the secret-card area scrolls as more cards are added
9. Browser/device responsive behavior retained, including mobile desktop-site mode.

IMPORTANT
---------
Cross-device game progress is still stored locally in each browser.
True phone/laptop progress sync still needs a cloud backend.
